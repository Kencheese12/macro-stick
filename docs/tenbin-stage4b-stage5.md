# 段階4（B案やり直し）＋段階5（筐体.scad）メモ（2026-11-24受領）

## B案確定寸法
- 全長 111.7mm（A案128.5から短縮。約110の見込みより+1.7は USB-C奥端とCKW12 A/B/Cピンの間隔0.85mm確保のため）、高さ17.7mm不変
- XIAOはCKW12真下・基板裏面、部品面を上（メイン基板側）にしてヘッダ吊り下げ、すき間4.0mm。USB開口中心 z=6.4
- CKW12中心 y=18.0（筐体座標）、MP削除。キー中心 37.05/56.10/75.15/94.20
- メイン基板 19.0×101.9mm。プレート 19.4×76.6（y=27.775〜104.375）。下端ボス y=108.1
- 電池はXIAO裏パッド19（VBAT）/20（GND）に直付け。J1・TP1・TP2は削除。JLC実装はソケット×4のまま
- 底板 19.5×107.4。XIAO裏パッド逃げ（深さ1.0）・電池リード溝・XIAO後端ストッパー付き
- デメリット追加：XIAOの充電LED/RGB LEDが見えない（残量はBLE通知で確認）
- 基板端0.0425mm問題はB案で解消（DIP穴ランド外端まで基板端1.03mm）

## リセット（天秤が訂正）
- B案ではリセットボタンがメイン基板側を向くため、分解しても押せない。「キーコンボ＋物理ボタン」は不成立
- 代替：①キーコンボ（&bootloader、主）②パッド17（EN）＋18（GND）ショート×2でUF2（底板を外すだけ）③基板にΦ2.0 NPTH穴を開けてピンでボタン押し ④SWDデバッガ（最終手段）
- **Muse調査（2026-11-24）**：Seeed Wiki系ピンマップに裏面パッド「RST = Reset (P0.18)、GNDに接続でリスタート」の記載あり（chiptronの底面パッド表、Seeed Wikiの Pin Map にも Reset P0.18）。パッド17の「EN」表記は共通シンボルの命名で、実体はnRESETの可能性が高い → ②が成立する見込み。最終確認はSeeed回路図か実物の導通チェック
